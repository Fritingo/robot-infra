Robot-Infra v3 — 純內網多使用者 GPU 機器人開發平台

專為無外網連線（Air-Gapped）、單一 Ingress IP 受限環境與多型號 GPU 混部叢集（共存 H200 / H100 / A100 / B300，嚴格僅觸及 RTX PRO 6000）打造。 整合 Selkies v2.2.1 EGL Desktop、ROS 2 Jazzy + MoveIt 2 + 預設 CycloneDDS（lo 直通 Podman/Docker）、跨 Pod ros-bridge（Ingress /zenoh WSS + 選配純 CPU Hub）、無特權 Rootless Podman 與共用唯讀 Isaac Sim 6.2。

隔離面向v3 實作機制保證結果

零 Host OS 與全叢集污染100% Namespace-scoped（robotics），零 ClusterRole/CRD/Webhook；privileged: false、hostNetwork/PID/IPC: false、6 項最小 Capabilities、客製 Seccomp不改動宿主機核心／網路／sysctl，不更動其他 Namespace 或 Ingress Controller 全域旗標

2系統架構與網路拓撲

3三種純內網傳輸模式比較

WebRTC UDP Mux + ICE-lite（多人最低延遲・水平分散負載）

每位使用者配置 1 個全域唯一 UDP hostPort（50001..50999），Downward API 自動帶入排程到的 GPU 節點 status.hostIP，零中繼瓶頸、零外網 STUN。

關鍵啟動參數
SELKIES_MODE=webrtc
SELKIES_ENABLE_DUAL_MODE=true        # 側邊欄仍保留一鍵切 WebSockets 保底
SELKIES_WEBRTC_ICE_LITE=true
SELKIES_WEBRTC_UDP_MUX_PORT=50001    # 同步設 containers[0].ports[3].containerPort/hostPort
SELKIES_WEBRTC_PUBLIC_IP=<status.hostIP>
SELKIES_RTC_CONFIG_JSON=/etc/selkies/rtc-config.json

內部共用 Coturn 中繼（客戶端無法直連 GPU 節點時適用）

在 charts/robotics-infra/values.yaml 開啟 coturn.enabled: true，全叢集共用單一邊界節點進行 HMAC 驗證的 UDP 中繼。

啟用共用 Coturn 並指定邊界 IP
helm upgrade --install robotics-infra ./charts/robotics-infra \
  -n robotics --create-namespace \
  --set coturn.enabled=true \
  --set coturn.externalIp=192.168.10.50 \
  --set coturn.existingSecretName=coturn-turn-secret

純 WebSockets 模式（零 UDP 防火牆規則，100% 單一 Ingress TCP 443）

於使用者 kustomization.yaml 加入 ../../components/transport-websockets，自動移除 UDP hostPort 並切換 SELKIES_MODE=websockets。

k8s/users/<user>/kustomization.yaml
components:
  - ../../components/seccomp-podman-localhost
  - ../../components/transport-websockets

11常見問題排解（Troubleshooting）

Web 桌面連線黑畫面或 WebRTC 持續轉圈？
1. 確認防火牆放行辦公電腦至 GPU Worker Node 的 UDP 埠段（50000-51000）。
2. 可先於 Selkies 網頁側邊欄切至 WebSockets 模式立即驗證。
3. 確認 robotics Namespace 存在 selkies-airgap-rtc-config ConfigMap。
Podman 報 cannot clone 或 create keyring: Operation not permitted？
確認節點 /var/lib/kubelet/seccomp/profiles/podman-rootless.json 已分發並啟用 components/seccomp-podman-localhost（Ubuntu 24.04 AppArmor 限制請一併啟用 components/apparmor-unconfined），且 config/containers.conf 維持 keyring = false 與 default_sysctls = []。
Podman 報 fuse: device not found？
確認 /home/ubuntu/.local/share/containers 已獨立掛載實體 ext4/xfs PVC（selkies-podman-pvc）或本機 Docker Volume，避免 overlay-on-overlay。
launch-isaac-sim 報找不到 NVIDIA Vulkan 裝置？
請確認 Pod 申請的是 RTX PRO 6000 +gfx MIG Profile（含 RT Cores 與渲染引擎）且環境變數已注入 NVIDIA_DRIVER_CAPABILITIES=all。
